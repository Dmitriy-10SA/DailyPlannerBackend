# Функциональные требования

1. Система должна позволять авторизованному пользователю просматривать свои мероприятия за выбранный день.
2. Для каждого мероприятия должны храниться название, место, дата и время начала, дата и время окончания.
3. Система должна позволять добавлять мероприятие в расписание пользователя.
4. Система должна позволять редактировать мероприятие пользователя.
5. Система должна позволять удалять мероприятие пользователя.
6. Система должна иметь возможность отсортировать мероприятия от ближайшего к более позднему по началу.
7. Система должна поддерживать поиск мероприятий пользователя по названию и месту.
8. Поиск по названию и месту должен поддерживать частичное совпадение без учета регистра.
9. Время окончания мероприятия должно быть позже времени его начала.
10. Пользователь должен иметь доступ только к собственному расписанию.
11. Система должна позволять неавторизованному пользователю зарегистрироваться, войти в аккаунт и изменить пароль.
12. Система должна позволять авторизованному пользователю выйти из аккаунта.
